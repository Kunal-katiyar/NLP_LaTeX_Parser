# <Name Pending>

A Google Chrome extension that converts from handwriting to clean LaTeX code, inside of a popup window that's directly embedded into your browser for convenience!

### ⭐ Features
<ul>
  <li>Resizable and Hideable Canvas Window, can be expanded to the whole screen or just in a corner</li>
  <li>Live Conversion from handwriting to LaTeX, automatically updating the copyable info</li>
  <li>Light/Dark Modes that match the browser/device settings</li>
  <li>Customizable Stroke Color</li>
</ul>

### 🔭 Works in Progress 
<ul>
  <li>Saving Handwriting and LaTeX data across browser tabs</li>
  <li>Customizable Stroke Width and Grid Color</li>
</ul>
